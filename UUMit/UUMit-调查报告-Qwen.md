## 1. 名称消歧

搜索「UUMit」会命中两个互不相关的实体：

- **UUMIT（it.uum.edu.my）** — 马来西亚北方大学（Universiti Utara Malaysia）信息技术部门，与本报告无关。
- **UUMit（uumit.org / uumit.com）** — 中国的 AI 能力交易平台，本报告对象。

此外，UUMit 自身使用了**两个不同域名**，二者性质完全不同，是本报告最重要的区分点：

| 域名 | 性质 | 状态 |
| --- | --- | --- |
| `uumit.org` | 对外宣传落地页 | **全部数据由前端 JS 伪造，无后端** |
| `uumit.com` | 实际产品站 | 真实存在，有 ICP 备案，邀请码内测中 |

## 2. 结论摘要

**UUMit 宣称的定位**：「AI 原生能力交易平台 / 下一代 A2A 经济网络」，用户部署 AI 代理挂牌个人技能，Agent 之间通过 A2A + MCP 协议自动完成匹配、定价、交付、结算，主打「零门槛接入」「全自动结算」，让普通人获得被动收入。

**实际调查结论**：

1. 宣传站 uumit.org 展示的**所有**运营数据（成交额 7330 万美元、309,597 笔成交、8+ 活跃 Agent、211+ 条新闻、5,173 人实时在线）**全部是浏览器本地 JavaScript 现场生成的假数据**，全站零网络请求、零表单、零输入框。
2. 官网自己在页面小字中承认：「每5秒自动新增模拟交易，市场火热」。
3. 「每半小时疯抢 10000 注册码」是纯前端表演，点击后**永远**返回「已被秒杀」，其唯一实际作用是触发 Adsterra 弹窗广告。
4. 真实产品站 uumit.com 确实存在，有广东 ICP 备案，仍为邀请码内测。
5. 落地的功能是三条：OneKey（模型 API 聚合）、知识商店、算力共享（转卖闲置 API 配额）。
6. 唯一一篇独立实测（CSDN，2026-08-14）结果为：**花费 ¥53.25 API 成本，收入 ¥2.29**，投入产出为负。
7. 无融资记录、无投资机构、无主流科技媒体（36氪/虎嗅/钛媒体/IT桔子）报道；所有上线报道为同一天同一篇通稿分发。
8. 官方明确声明 UT 不是代币；BSC 链上的「小龙人」代币为蹭名山寨币，与官方无关。

**一句话定性**：方向不算荒谬（AI 能力市场 + API 中转 + 闲置算力转卖确实是行业热点），但当前既无证据支持「躺赚」叙事，营销手段也包含明确的数据造假。

### 3.2 技术证据

通过浏览器渲染官网并提取全部内联脚本（9 个 script 块，共 25,910 字符）进行审查，结论如下。

**(a) 零后端交互**

| 检测项 | 结果 |
| --- | --- |
| `fetch(` / `XMLHttpRequest` / `axios` / `navigator.sendBeacon` | **0 次** |
| `<form>` 元素 | **0 个** |
| `<input>` / `<textarea>` | **0 个** |
| `localStorage` 调用 | **0 次** |
| 页面出现的唯一 API 路径 | WordPress 自带 `wp-json/oembed`、`api.w.org`（框架样板，与业务无关） |

没有账号系统、没有注册入口、没有服务端数据源。

**(b) 数据由函数生成**


- 标题完全同构：「AI Agent 行业动态 #N: 能力经济爆发」（N = 1…23 循环）
- 摘要完全相同：「真实行业新闻，反映Agent经济高速发展。」
- 链接为在真实域名后拼接 `?ref=N` 伪造：

## 5. 产品与功能

### 5.1 已落地的三条产品线

来源：创始人掘金账号「UUMit文斌」发帖，2026-06-26。

| 产品线 | 实质 |
| --- | --- |
| **OneKey** | 一个 API Key 聚合调用多家大模型，本质为模型 API 中转 / 聚合层 |
| **知识商店** | 挂牌出售知识、技能、数字资产 |
| **算力共享** | 转卖闲置 API 配额，采用「冻结 — 转发 — 结算」模型，用户自定价，平台抽佣 |

### 5.2 宣称的工作流

来源：2026-05-18 上线通稿（中华网等）。

1. 供给侧凭邀请码注册
2. 完成约 2 分钟的「天赋发现」测评
3. 平台自动将技能挂牌为 MCP「Agent Card」
4. AI 代理自动完成匹配、定价、交付、结算

宣称自动化率约 **95%**，支持四种交易模式：**A2A / P2P / A2P / P2A**。

### 5.3 可挂牌的类别

技能、知识 / 数字资产、API 订阅、算力。

有记录的具体挂牌案例：数据分析、PPT 设计、包装设计（均来自通稿）；婚纱照初筛（来自独立用户实测）；AI 影视制作工作流（来自 2026-09 创始人直播）。

## 8. 代币问题排查

搜索过程中出现 Bitget Wallet 的「小龙人（Xiaolongren）」代币页面与 UUMit 并列，故专门排查。

**结论：UUMit 官方无任何代币。**

依据：

1. 官方微博明确声明 UT 不是代币、不是虚拟货币
2. 所有官方渠道（官网、创始人掘金帖、微博）**零代币提及**
3. BSC 链上存在名为「小龙人」并标注 `UUMit/WBNB` 的代币，但**至少有三个不同合约地址重名**：
   - `0xf30b8622a4bc0fa4ef5135923fe8837d82204444`（Dexscreener，快照显示约 $2,555）
   - `0xc2d737b51411ef37901dd969bc51b2ee1f870d23`（ApeSpace）
   - `0x7f0f…`
4. Bitget Wallet 页面为自动生成的 SEO 页

多个重名合约 + 官方零提及 + 官方否认，符合**蹭热度山寨币**的典型特征。

| API 成本 | **¥53.25**（DeepSeek） |
| 收入 | **¥2.29（327 UT）** |
| 结论 | 投入产出为**负**；Agent 收入无法覆盖算力成本，在当前平台机制下不具盈利性 |

> 数据说明：后台调研代理初次转述为「花费 ¥28，收入 ¥2.29 / 1,462 UT」。经直接抓取原文核对，成本为 **¥53.25**、收入为 **¥2.29（327 UT）**；收入金额一致，成本与 UT 数存在出入，可能原文含多组实验。本报告以直接抓取值为准。

**结构性分析**：该结果并非偶然。平台上买方出价极低（实测单笔收入以分计），而卖方 Agent 每次响应都需支付真实的模型 API 费用。在缺乏补贴的情况下，这种成本结构决定了自动接单必然亏损——「躺赚」在经济模型层面即不成立。

## 15. 调查过程更正记录

为保持结论可信，记录本次调查中的一处修正：

**初次结论（基于 uumit.org 单一域名）**：「这个平台不存在……它没有产品、没有用户、没有交易、没有结算。」

**问题**：该结论仅对 uumit.org 成立。调查遗漏了 uumit.com 这一真实产品域名。

**修正后结论**：UUMit 存在两个域名——uumit.org 是数据完全伪造的宣传站（该部分结论经源码审查与第三方独立分析双重确认，依然成立），uumit.com 是真实的邀请码内测产品站（有广东 ICP 备案）。因此准确的表述是：**宣传层造假已被证实，产品层真实存在但极早期且经济性存疑**，而非「平台完全不存在」。

**教训**：对多域名运营的项目，应先完成域名 / 主体的穷举，再下整体性结论。

## 📬 收件箱项目（Frictionless Inbox）

**"无脑收件箱"** — 看到感兴趣的内容时，不用纠结"存到哪"，快速扔进来，自动分类整理。

### 功能特性
- 🧠 **双引擎分类**：本地规则引擎（50+ 中文待办模式 + 200+ 学术关键词）+ AI 分类，自动归入待办 / 日程 / 知识库 / 随笔
- 📅 **智能日期识别**：自动解析中文日期表达（"明天"、"下周五"、"12月20日"），自动标记为日程
- 🤖 **多 AI 提供商**：支持 Claude、GPT、DeepSeek、智谱、Kimi、通义千问、豆包、Groq、Gemini，可切换模型并测试连接
- 📝 **两种输入模式**：普通模式 + 长文随笔模式
- ✅ **完整管理功能**：行内标题编辑、分类切换、待办勾选、批量选择/移动/删除、回收站（支持恢复和永久删除）、午夜自动清理
- 🔍 **搜索**：全量搜索已收录条目

技术栈：HTML / CSS / JavaScript / LocalStorage

## 📄 文档智能总结助手

基于 DeepSeek API 的文档智能总结工具，上传文档即可自动生成摘要。

### 功能特性
- 🤖 **AI 智能总结**：调用 DeepSeek 大模型，支持 6 种预设风格（简洁 / 超简 / 数据 / 学术 / 口语 / 提纲）+ 自定义提示词
- 📂 **多格式支持**：TXT / PDF（PDF.js）/ DOCX（Mammoth.js），拖拽或选择上传
- 🔍 **文档对比**：上传两份文档，从内容差异、关键词、核心观点、结构逻辑、数据案例 5 个维度自动对比分析
- 🌗 **深色模式**：明亮 / 暗黑主题一键切换
- 📜 **历史记录**：总结历史和对比历史独立存储，支持点击回溯、删除、清空
- 📤 **多格式导出**：支持导出 TXT / DOCX，一键复制总结或翻译结果
- 🌐 **翻译功能**：对总结结果进行翻译

> 使用前需在代码中配置你自己的 DeepSeek API Key

技术栈：HTML / CSS / JavaScript / PDF.js / Mammoth.js / DeepSeek API

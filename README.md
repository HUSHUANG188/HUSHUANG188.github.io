## 1. 微信开发 · 虚拟冰箱

微信小程序，把家里的冰箱"搬"到手机上 —— 记录食材、临期提醒、家庭共享，还能根据现有食材让 AI 推荐菜谱。

### 功能模块

| 模块 | 说明 | 云函数 |
|---|---|---|
| 食材与库存 | 冷藏/冷冻/门架分区管理，支持门体自由布局与 DIY 编辑器 | — |
| 家庭共享 | 一个冰箱多人共用，成员与数据同步 | `family` |
| AI 配餐 | 根据现有食材生成菜谱建议，带额度控制 | `mealAi` |
| 小票识别 | 拍照识别购物小票自动入库，含分类记忆 | `receiptOcr` |
| 临期提醒 | 到期前自动提醒 | `reminders` |
| 数据生命周期 | 备份、导出、隐私数据清理 | `dataLifecycle` |

### 项目结构

```
微信开发/虚拟冰箱/
├── app.js / app.json / app.wxss     # 小程序入口
├── pages/                           # 页面
├── components/navigation-bar/       # 自定义导航栏
├── utils/                           # 业务逻辑（door / family / food / meal / receipt …）
├── cloudfunctions/                  # 6 个云函数
│   ├── family/                      # 家庭共享
│   ├── mealAi/                      # AI 配餐
│   ├── receiptOcr/                  # 小票 OCR
│   ├── reminders/                   # 提醒
│   ├── dataLifecycle/               # 数据生命周期
│   └── …
├── cloudbase/                       # 数据库 / 存储 / 云函数安全规则
├── tests/                           # 19 个 Node 测试用例（.cjs）
└── artifacts/                       # v4 / v6 验收截图
```

配套文档：`DESIGN.md`、`BACKUP_SETUP.md`、`REMINDER_SETUP.md`、`V5_SETUP.md`，以及多份代码评审、问题清单与交接记录。

## 2. 文档智能总结助手

基于 DeepSeek API 的文档智能总结工具，上传文档即可自动生成摘要。

### 功能特性

- 🤖 **AI 智能总结**：支持 6 种预设风格（简洁 / 超简 / 数据 / 学术 / 口语 / 提纲）+ 自定义提示词
- 📂 **多格式支持**：TXT / PDF（PDF.js）/ DOCX（Mammoth.js），拖拽或选择上传
- 🔍 **文档对比**：上传两份文档，从内容差异、关键词、核心观点、结构逻辑、数据案例 5 个维度自动对比分析
- 🌗 **深色模式**：明亮 / 暗黑主题一键切换
- 📜 **历史记录**：总结历史和对比历史独立存储，支持点击回溯、删除、清空
- 📤 **多格式导出**：支持导出 TXT / DOCX，一键复制总结或翻译结果
- 🌐 **翻译功能**：对总结结果进行翻译

当前版本：`app_docx16.html`　|　历史版本：`app_docx1.html` ~ `app_docx15.html`

> 使用前需将代码中的 API Key 占位符替换为你自己的 DeepSeek API Key。

技术栈：HTML / CSS / JavaScript / PDF.js / Mammoth.js / DeepSeek API

## 3. 收件箱项目（Frictionless Inbox）

**"无脑收件箱"** —— 看到感兴趣的内容时，不用纠结"存到哪"，快速扔进来，自动分类整理。

### 功能特性

- 🧠 **双引擎分类**：本地规则引擎（50+ 中文待办模式 + 200+ 学术关键词）+ AI 分类，自动归入待办 / 日程 / 知识库 / 随笔
- 📅 **智能日期识别**：自动解析中文日期表达（"明天"、"下周五"、"12月20日"），自动标记为日程
- 🤖 **多 AI 提供商**：支持 Claude、GPT、DeepSeek、智谱、Kimi、通义千问、豆包、Groq、Gemini，可切换模型并测试连接
- 📝 **两种输入模式**：普通模式 + 长文随笔模式
- ✅ **完整管理功能**：行内标题编辑、分类切换、待办勾选、批量选择/移动/删除、回收站（支持恢复和永久删除）、午夜自动清理
- 🔍 **搜索**：全量搜索已收录条目

当前版本：`index_v4.html`　|　历史版本：`index_v1.html` ~ `index_v3.html`

技术栈：HTML / CSS / JavaScript / LocalStorage

## 4. 番茄钟

番茄工作法计时器，目录下保留了 5 个演进版本：

| 目录 / 文件 | 说明 |
|---|---|
| `pomodoro-best/` | **最佳版** ⭐ 集合下面几版的优点，并修复了原版问题 |
| `pomodoro-timer/` | 功能较完整的版本，含圆形进度环与部署说明 |
| `pomodoro/` | 含今日 / 累计统计的版本 |
| `pomodoro.html` | 单文件早期版 |
| `promodoro-chrome/` | Chrome 扩展版（含 `index-fixed.html`） |

`pomodoro-best/` 的主要改进：用"目标结束时间 − 当前时间"计算剩余，切后台不漂移；跳过不计入番茄数；每 4 个番茄自动进入长休息；深色模式、快捷键、提示音与桌面通知、标签页倒计时。

技术栈：HTML / CSS / JavaScript（纯静态，无依赖、无构建）

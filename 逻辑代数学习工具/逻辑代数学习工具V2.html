🔌 用与非门 / 或非门实现（通用门）

与非门实现（NAND-only，两级）

原理：两级与非 —— 第一级对每个积项取非，第二级把取非后的结果相与非。

或非门实现（NOR-only，两级）

原理：两级或非 —— 第一级对每个和项取非，第二级把取非后的结果相或非。

与非（NAND）：二变量 (A·B) = A + B；三变量 (A·B·C) = A + B + C
或非（NOR）：二变量 (A+B) = A · B；三变量 (A+B+C) = A · B · C
通用性：NAND 与 NOR 各自都能实现 与/或/非，是“通用门”。

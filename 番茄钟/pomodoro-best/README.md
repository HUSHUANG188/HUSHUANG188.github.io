# 🍅 番茄钟 · 最佳版

集合工作文件夹里三版番茄钟（`pomodoro.html` / `pomodoro/` / `pomodoro-timer/`）的优点，并修复了原版的问题。

## ✨ 特性

| 特性 | 说明 |
|---|---|
| **精确计时** | 用「目标结束时间 − 当前时间」计算剩余，切后台/卡顿不漂移（取自 `pomodoro-timer`） |
| **自动开始下一段** | 可勾选，一段结束自动进入下一段（取自 `pomodoro-timer`） |
| **跳过按钮** | `⏭` 跳到下一阶段，**不计入番茄数**（修复了原版跳过也算完成的 bug） |
| **今日 + 累计统计** | 今日番茄数按天自动归零，累计数永久保存（取自 `pomodoro/`，修正"轮"错标为"个番茄"） |
| **4 格本轮进度** | 显示当前这一轮已完成几个番茄（取自 `pomodoro-timer`） |
| **长休息轮换** | 每 4 个番茄自动进入长休息，否则短休息 |
| **深色模式** | 自动跟随系统（取自 `pomodoro-timer`） |
| **快捷键** | `空格` 开始/暂停 · `R` 重置 · `S` 跳过 |
| **提示音 + 桌面通知** | Web Audio 三连音，无需外部文件 |
| **标题栏倒计时** | 浏览器标签页实时显示剩余时间 |
| **设置即时生效** | 时长直接编辑保存；计时中修改则下一轮生效 |

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何环境。

也可以起本地静态服务器：

```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

然后访问 http://localhost:8000

## ⌨️ 快捷键

- `空格` — 开始 / 暂停
- `R` — 重置当前段
- `S` — 跳过当前段（不计数）

## 📊 数据存储

所有数据保存在浏览器 `localStorage`，使用 `pb.*` 前缀（与原版互不干扰）：

- `pb.settings` — 时长设置
- `pb.autoStart` — 是否自动开始下一段
- `pb.count` — 今日番茄数 / 累计数 / 本轮进度（跨天自动重置今日数与本轮进度）

## 🔧 相比原版修复的问题

1. **计时漂移**（原 `pomodoro.html`、`pomodoro/` 用每秒减一）→ 改用目标时间戳算法
2. **跳过也算完成**（原 `pomodoro/` 的 `skip()` 直接走完成逻辑）→ 跳过不计数
3. **统计错标**（原 `pomodoro/` 每个番茄完成就 +1 却叫"轮"）→ 改为累计番茄数
4. **空格键双重触发**（原 `pomodoro/` 按钮聚焦时按空格会同时触发按钮点击与快捷键）→ 统一用 `preventDefault` 接管
5. **死代码**（原 `pomodoro.html` 残留空 if 块）→ 移除
6. **本地数据未校验**（损坏/超范围时长会导致异常）→ 加载时统一钳制回合法范围
